# rspencerfink.com

Next.js (App Router) portfolio, statically generated and hosted on Vercel. Design spec: `docs/redesign/design-spec.md`. Architecture and track seams: `docs/redesign/ARCHITECTURE.md`.

```
npm install
npm run dev        # http://localhost:3000
npm run build && npm start   # production build on http://localhost:3000
npm run lint && npm run typecheck
```
